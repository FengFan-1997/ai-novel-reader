# 小说多角色音色调研：崩铁 / 原神角色参考

更新时间：2026-07-27

## 先说结论

公开仓库里能找到一些角色 RVC 音色转换模型，但它们不是官方发布的专业 TTS，也不能单独把文字自然地朗读出来。适合的技术链路是：

`小说文本 → 中文 TTS 负责连读、停顿、语气和情绪 → RVC 只转换音色`

这些角色包应只进入本地、非商业的“试音实验室”，默认不随产品分发。面向公开产品，应使用获得授权的声音，或根据角色气质设计不指向具体演员和游戏角色的原创音色。

## 技术选型

### RVC 试音层

- [mason369/AI-RVC](https://github.com/mason369/AI-RVC)：MIT 代码许可，支持 MPS / CPU / CUDA，能直接使用常见 RVC v2 的 `.pth + .index`，适合作为当前 Mac 上的首选试音实现。
- [Acelogic/Retrieval-based-Voice-Conversion-MLX](https://github.com/Acelogic/Retrieval-based-Voice-Conversion-MLX)：面向 Apple Silicon 的 MLX 实现，性能主张有吸引力，但项目较新，仓库许可标注和成熟度仍需进一步核验。
- [RVC-Project/Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI)：主流参考实现，功能完整，但对当前轻量产品集成偏重。

### 产品音色层

- 保留现有中文 TTS 作为“表演层”，负责正常中文连读、标点停顿、对话语气和情绪。
- 使用 VoiceDesign 或有授权的短参考音频生成原创角色音色。
- 角色识别、情绪判断、TTS、RVC 分层，便于逐项替换和 A/B 试听。

## 验收标准

任何音色在进入默认列表之前，都必须通过同一组中文小说片段：

1. 旁白、连续长句和成语不能一字一顿。
2. 问句、感叹、插话、犹豫和低声说话要有明显区别。
3. 同一人物跨段落音色稳定，不突然变调或换性别。
4. 女童音不刺耳，成熟女声不油腻，男低音不含混。
5. RVC 转换后没有明显电流声、金属音、吞字和辅音破裂。
6. 角色包的来源、模型许可和可分发范围必须有记录。

## 下载策略

先下载体积较小且来源可追溯的 `.pth + .index` 做隔离试音，不下载训练数据集，也不把社区角色权重提交到 Git。没有清晰许可、没有试听样例或只存在于网盘聚合站的模型暂不使用。
