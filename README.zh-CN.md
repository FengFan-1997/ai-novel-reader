# 中文零成本 AI 小说朗读

这是基于 TTS-Story 的中文优先分支：完全本地运行，不购买 API；Ollama + Qwen3
识别旁白和对白；Qwen3-TTS 通过 MLX 使用多种中文声线；原生识别“第一卷、第一章、
序章、楔子、番外、尾声”等中文结构。

## 要求与成本

- Apple Silicon Mac（建议 16GB 内存）
- 首次下载时联网，之后可离线
- 使用原有 Qwen3-TTS 时硬盘预留约 10GB；启用 IndexTTS2 情绪模式时建议再预留
  约 12GB（主权重约 5.5GB，另有声纹编码器、声码器与独立运行环境）
- 启用八重神子社区 RVC 旁白时，独立环境、基础模型和角色模型约再占 2GB

软件、模型和本地推理没有调用费。“零成本”不包含电脑、电费和首次下载流量。
IndexTTS2 权重使用 bilibili Model Use License，并非 Apache/MIT；个人本地使用免费，
若未来公开分发或达到其超大规模商业门槛，需要按仓库许可证重新核对合规条件。

## 安装与启动

```bash
chmod +x setup-macos-zero-cost.sh run-macos-zero-cost.sh
./setup-macos-zero-cost.sh
./run-macos-zero-cost.sh
```

模型仓库、首次下载时机、资产校验边界，以及另一台电脑的安装要求见
[`docs/model-assets.zh-CN.md`](docs/model-assets.zh-CN.md)。

启动后在浏览器访问 `http://localhost:7860`。默认先用
`mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-8bit` 自动建立角色声纹，再用
1.7B Base 8-bit 模型锁定声纹并朗读正文。两个模型首次使用时各下载一次，之后均
从本机缓存加载。

## 找书神器

打开侧栏的“找书”，输入书名、作者或 ISBN。Google Books 与 Open Library 可直接使用；
起点、番茄、晋江、微信读书和自定义网站可由公开搜索页或本机 SearXNG 汇总入口发现。
搜书吧的“发布页”和“当前搜索站”分开管理：发布页可能是带非标准端口的 HTTP 地址，
声阅只从中读取“最新地址”，绝不向它发送账号；发布页指向的当前站通过 HTTPS、品牌和
搜索入口验证并由用户确认后，才允许使用用户合法拥有的账号走原站登录与站内搜索流程。
登录失效或出现验证码时会要求回到原站手动处理。
同一本书会按 ISBN、书名与作者合并，成人来源会逐条显示醒目标记。
Project Gutenberg 和 Google Books 明确提供的公开文件会显示“下载 TXT/EPUB/PDF”；
Open Library 及商业、登录或银币来源统一显示“去原站阅读/获取”，由原站完成授权、
购买或下载确认，声阅不会代扣费用或绕过访问控制。

SearXNG 是可选的本机 Docker 服务，需要 Docker Desktop（含 Docker Compose）。安装
脚本只准备配置，绝不会擅自启动 Docker Desktop。先手动启动 Docker Desktop，再运行：

```bash
cd search-stack
docker compose up -d
```

服务只绑定 `127.0.0.1:8888`。完整配置、健康检查和停止命令见
[`search-stack/README.zh-CN.md`](search-stack/README.zh-CN.md)。SearXNG 停机时页面会
显示降级提示，直连书目来源仍可正常搜索。

找书页只保存最近 100 条搜索词与主动收藏的元数据，不缓存来源网页或受保护正文；
账号只允许在本机配置并写入 macOS Keychain。声阅不破解验证码、登录、付费或访问
控制，也不代理下载。只有专用适配器能确认属于公版或开放授权的纯文本时，未来才会
显示“导入声阅”，其他结果一律打开原站。

## 免费声阅助手

每个 React 页面右侧都有“问声阅”页签。它会把当前页面名称、作品名称和文字数量等
简要状态连同声阅操作手册交给本机模型，回答“下一步点哪里”；小说正文、密码、验证码
和 API Key 不会进入对话。助手只提供真实页面入口，不会假装已经替用户登录、付款、
删除、下载或启动服务。

切换输入框上方的“找书并制作”后，可以只输入一个书名。声阅会同时查搜书吧和公开
书库；若只有一个书名完全匹配、明确公版/开放授权并提供 TXT 的版本，会自动校验下载
地址、获取正文、建立本地作品并启动首章处理。搜书吧“免费”附件、登录内容、同名版本
或版权未知内容不会自动下载，而会保留本次候选等待用户确认。

默认复用 Ollama 的 `qwen3:1.7b`。也可以在“设置 → 免费 AI 助手”切换为 LM Studio，
选择已经安装或加载的模型。Ollama 默认地址为 `http://localhost:11434`，LM Studio
默认地址为 `http://localhost:1234/v1`。声阅不会自动下载大型模型，也不会自动启动
模型服务。

站内操作提示词单独保存在
[`prompts/site_assistant.zh-CN.md`](prompts/site_assistant.zh-CN.md)，与小说分角色提示词
完全隔离；修改操作流程后可以直接更新该文件。助手 API 为
`GET /api/site-assistant/status` 和 `POST /api/site-assistant/chat`，只允许连接本机回环
地址的 Ollama/LM Studio，且不会返回已保存的 API Key。

## 边生成、边播放

1. 导入或粘贴小说，点击底部的“生成并听”。这一入口固定使用本地 Qwen3 MLX，
   先分析章节与人物，再逐段发布音频，不必等整本完成。
2. 机器生成足够快时，达到 90 秒安全缓冲即可播放；生成较慢时会先完成第一章，
   避免听到一半中断。
3. 播放当前章时会继续制作下一章；默认领先一章后暂停。需要无人播放时继续制作，
   再开启底栏的“后台生成整本”。
4. 跳到尚未生成的章节会自动提高该章优先级。播放位置、倍速与章节会保存，刷新或
   重启服务后可以继续。
5. 旁白默认使用“狐系御姐”的表演参数。安装八重神子社区 RVC 后，只有旁白会转换
   音色，男性和女性对白绝不会进入 RVC：

```bash
./scripts/setup-yae-rvc.sh
```

RVC 安装在 `data/rvc` 的独立 Python 3.10 环境，失败时自动回退原始旁白，不会让
整章任务失败。社区模型的角色及演员声音授权需要使用者自行确认，尤其是公开发布或
商业使用。
仅含 `“……”` 的片段会转换为自然停顿；有效文本偶发空音频时会在同一声线下自动
重试。失败章节手动重试时从首个未完成片段续跑，已完成音频不会重新生成。

## 最小验证

1. 把 `example_story_zh.txt` 拖入网页并运行 AI 文本处理。
2. 在生成页面选择 `Qwen3-TTS · 中文角色声线`，从 37 条原创中文声线中为角色
   选角；列表按“崩坏：星穹铁道人设参考 / 原神人设参考 / 通用旁白”分组。
3. 给旁白和人物分配不同预设，也可以调整音高、语速和语气。
   “Auto Assign”会根据人物档案、性格与角色标签推荐声线，也可逐人物查看和采用推荐。
4. 直接生成小说。系统会根据对白、前后旁白和“低声道、厉声喝道、红着脸”等
   说话动作，自动判断自然、兴奋、温柔、娇羞、冷峻、危险、愤怒、悲伤哭腔或低声。
   情绪线索较弱的相邻句会延续同一人物上一句的状态，避免一句一换；正文里显式
   写出的情绪标签和角色页的手动情绪选择始终优先。
5. 需要明显的情绪表演时，在设置里选 `IndexTTS2 · 中文情绪阅读`。它复用已建立的
   人物声纹作为身份参考，同时把情绪作为独立向量送进合成器；这样情绪变化时尽量
   保持还是同一个人。界面的“情绪表现强度”可以从 0 到 1 调整，内部实际混合强度
   对普通状态限制在官方建议的 0.6 以内；愤怒、兴奋和悲伤哭腔使用更明显的有声剧
   曲线；兴奋和悲伤哭腔最高限制在 0.82，愤怒可到 0.90。某条原创人物声线还没有本地声纹时，
   系统会先自动建立一条中性身份参考，不要求用户先去试听页面生成。

默认是 Ollama `qwen3:1.7b` 负责角色分析，MLX Qwen3-TTS 1.7B 8-bit 负责建立原创
人物声纹，IndexTTS2 负责带情绪的小说朗读。角色判断想要更稳，可以在设置里升级到
`qwen3:8b`，代价是更慢、占用更多内存。自动选角、声纹设计文本和声音设计均使用
标准中文普通话提示，不再用英文声乐分类指导中文角色。
Qwen3-TTS Base 适合锁定声纹和保证中文连读，但它不支持指令控制；因此仅靠给 Base
传“愤怒、温柔”等文字不会产生可靠表演。IndexTTS2 模式改为固定一条人物身份参考，
再由本地 0.6B 中文情绪分析器读取当前对白、前后旁白与连续状态，产生八维基础情绪。
该分析器没有“娇羞、冷峻、危险、低声”等复合表演类别，所以系统会把它的分数与
上下文导演给出的表演向量融合：自然、兴奋、愤怒、悲伤哭腔更多相信语义分析，复合状态更多相信
小说动作与人设，避免把危险的冷笑或娇羞的犹豫读成悲伤。同一人物相邻句的向量会做
小幅数值混合，避免表演突然跳档。正文明确标签与手动选择则直接使用确定的情绪向量。
两条路径都按情绪类别限制混合强度。过慢的
中文生成会触发一次节奏重试，避免用长停顿冒充“低沉、威严或神秘”。
